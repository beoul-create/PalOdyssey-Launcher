SUMMON AROUND AND FIND OUT - ARENA RAIDS
========================================

CURRENT VERSION
Single-boss Early Progression realm.

LEVEL RANGE
Lv33-Lv63

RAIDS
20 total raids.
Every raid summons exactly ONE boss.

FLAVOR UPDATE
Bosses now have unique funny names.
Reinforcements have themed funny names.
Every slab/tablet description identifies and describes the exact boss you will face,
states that it is a SINGLE BOSS RAID, and describes its reinforcement phases.

CRAFTING ORDER
The 20 internal slab/raid IDs remain numerically ordered 001-020 in ascending raid level.
Visible slab names retain [Lv 033] through [Lv 063] prefixes.

INSTALL
Place the SummonAroundAndFindOutArenaRaids folder inside:
Pal\Binaries\Win64\ue4ss\Mods\PalSchema\mods\

REQUIREMENTS
UE4SS Experimental
PalSchema

IMPORTANT
Do not run an older Early Progression or combined MoreRaidBossesComplete package
at the same time because they reuse the same custom Pal/raid identifiers.


UNIQUE SKILL LOADOUT UPDATE
---------------------------
All 20 bosses now have distinct skill loadouts with 4-10 active skills.
Every boss has one signature move that no other Early Progression boss receives.

Reinforcement Pals were diversified too and now carry 4-7 skills with unique
loadouts instead of repeating the same four-skill templates.

Every WazaID used by this update comes directly from the supplied 100%-working
More Raid Bosses reference mod.
