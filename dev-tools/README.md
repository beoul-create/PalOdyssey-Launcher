# 🛠️ PalOdyssey Developer Tools

This folder contains scripts and utilities for developers maintaining and testing the PalOdyssey Launcher.

### 📜 Available Scripts

- **`run-dev.bat`**: Builds and launches `PalLauncher` in Debug mode directly from source code.
- **`run-dev.ps1`**: PowerShell equivalent of the dev launcher runner.
- **`run-tests.bat`**: Executes the 89-test verification suite with detailed test reporter output.
- **`package-release.bat`**: Compiles the release binary and packages the clean `PalOdyssey-Launcher-v2.0.0.zip` for players.
